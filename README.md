# Касса — трекер доходов и расходов

Веб-приложение с регистрацией, входом и хранением данных в Neon. Фронтенд и API работают на Vercel.

## Локальный запуск

1. Скопируйте `.env.example` в `.env.local` и заполните значения.
2. Установите зависимости: `npm install`
3. Создайте таблицы: `npm run db:setup`
4. Запустите: `npm run dev`

## Стек

- Next.js
- Neon PostgreSQL
- Vercel
